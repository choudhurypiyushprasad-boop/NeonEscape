# Neon Escape

## 2D Survival Game using C# Windows Forms

Neon Escape is a simple 2D survival game developed using **C# and .NET Windows Forms**. The player must survive against enemies, collect energy orbs, and achieve the highest possible score.

## Features

- Player movement using WASD and Arrow keys
- Multiple enemies that chase the player
- Energy orb collection
- Score and high-score system
- 3 lives
- Enemy speed increases over time
- Player speed increases over time
- Survival timer
- Collision detection
- Game Over screen
- Restart functionality
- Neon-style graphical interface

## Technologies Used

- C#
- .NET
- Windows Forms
- Visual Studio
- GDI+ Graphics

## Project Structure

- `GameForm.cs` - Main game logic, controls and graphics
- `Enemy.cs` - Enemy class and enemy movement
- `EnergyOrb.cs` - Energy orb class and drawing
- `GameForm.Designer.cs` - Windows Forms designer code
- `Program.cs` - Application entry point
- `NeonEscape.csproj` - Project configuration

## How to Run

1. Clone or download this repository.
2. Open `NeonEscape.sln` or the project in Visual Studio.
3. Build the project.
4. Run the application.

## Gameplay

Move the player around the arena and avoid the enemies. Collect the yellow energy orbs to increase your score. The game becomes progressively more difficult as the enemies and player become faster.

Survive as long as possible and try to achieve a high score!
